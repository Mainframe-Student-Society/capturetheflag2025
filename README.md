# MaSS Capture The Flag (CTF) Platform
This repository contains the source code and resources for the MaSS Capture The Flag (CTF) Platform.

## Directory Structure
- `frontend/`: Contains the source code for the frontend of the CTF platform, including HTML, CSS, and JavaScript files.
- `backend/`: Contains the source code for the backend of the CTF platform, including server-side logic, database interactions, and API endpoints.
- `temp/`: All existing code, written by Aafrin (and ChatGPT).

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Flask (Python), SQLite (or eventually PostgreSQL)
